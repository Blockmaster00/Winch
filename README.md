
# Winch Mod

![Thumbnail](Preview.png)

This mod adds a winch system to the game Trailmakers, allowing players to attach and control winches for various purposes.

## Features

- Attach winches to vehicles and objects.
- Control winch extension and retraction.
- Adjustable winch settings for different scenarios.
- Multiplayer support with synchronized winch behavior.
- Customizable key bindings for winch controls.
